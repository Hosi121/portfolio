# Portfolio

HTML / CSS / JavaScript で構成する日英の個人サイトです。ビルドや依存パッケージのインストールは不要です。

`index.html` をブラウザで直接開くか、次のコマンドで確認できます。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

http://localhost:4173/ を開いてください。

## 構成と編集

- `index.html` / `en.html`：プロフィール、研究・活動記録。内容の更新は両言語に反映します。
- `styles.css`：生成りの背景、システムフォント、通常体の名前・見出し、スマートフォン対応。
- `garden.js`：Canvas 2D による花束・小鳥の ASCII 表現と、油絵風の筆跡。
- `og-garden.png`：リンク共有用の花束・小鳥の画像（1200 × 630 px）。日英共通で Open Graph / X のカードに指定し、通常のページ表示では読み込みません。
- レジュメは CV / PDF リンクから開けます。

冒頭の紹介文は、人と計算機の関わりを軸に、同意・プライバシー、OSS の推論高速化、触覚ゲルの開発をまとめています。「現在取り組んでいること」（英語では `What I'm working on?`）に「推論高速化 / 物質と計算機」を掲載し、その直下に研究関心を並べます。

画面構成は [kawak.in](https://kawak.in/)、文字の質感は [Dither Canvas](https://www.obsidianui.dev/docs/dither-canvas) を参考にしています。
花束を中心に、花の種類・配置・色、小鳥の向き・数・位置をページ読み込みごとに決めます。サイズ変更やポインター操作で構図は変わりません。

描画は初期化後、ポインター操作などがあるときだけ行います。常時描画するループ、動画、外部フォント、外部ライブラリは使用していません。
「動きを減らす」設定ではポインターによる変形を止めます。JavaScript 無効時も文字絵の代替表示、本文、実績の開閉、日英の切り替えが使えます。

共有画像は既存の `garden.js` の描画と名前を Chromium で静止画にしたものです。共有時はこの固定画像を使用し、サイト内の構図は引き続き毎回変わります。画像 URL・形式・幅・高さ・言語ごとの代替テキストを HTML のメタデータに記載するため、共有先で JavaScript を実行する必要はありません。仕様は [Open Graph](https://ogp.me/#structured) を参照してください。共有先が古いカードをキャッシュしている場合は、そのサービスでの再取得後に更新されます。

実績の開閉には HTML の `details` / `summary` を使用しています。既存の見出しへの URL は該当項目を開き、印刷時は全項目を展開します。
研究実績の「ポスター発表」「記事・解説」はそれぞれ初期状態で折りたたみます。NDSS 2025 の発表は「ポスター発表」に掲載し、タイトルに `(poster)` を付けます。採択実績では「助成・事業採択／チャレンジ」をフェローシップより先に掲載します。
研究・採択・受賞の補助リンク（details、poster、ACM DL、Official、最終審査会）は省略し、受賞のプレスリリース・新聞記事へのリンクは残します。母数等が不明な欄は表示しません。
受賞経験の「その他の受賞」はビジネスコンテストの下に配置し、テクノ愛2025・浜松市ウェルビーイングアイディアコンテスト・静大アイデアソン／データソン2025・COG 2024 の4件を初期状態では折りたたみます。
運営・管理経験は現在の活動を `開始年–：活動名` で先に掲載し、国際人工知能オリンピック日本委員会（JOAI委員会、2026年から）を先頭に、CPC（2024年から）を続けます。補足の小さい文字や外部リンクは省略します。「遍歴」に `2024–2025：ANCHOR（神経科学や認知科学の読書会を主宰）`、`2025：ChoiAca（研究イベントの情報集約サイトを運営）`、`2024–2026：IYNA (advisor)` を折りたたみます。

プレプリントの被引用数は [Semantic Scholar の論文ページ](https://www.semanticscholar.org/paper/6d885c9cfcb4643d9ead13f6b92b759def0002f6) にリンクしています。2026-09-23 に [公式 API](https://api.semanticscholar.org/graph/v1/paper/ARXIV:2503.02142?fields=title,url,citationCount) の `citationCount` で9件を確認しました。取得時点の静的な値を日英に記載し、実行時の API 通信は追加していません。

## OSS の掲載方針

「推論高速化」の枠内で「提案中」と「マージ済み」に分け、各項目は `repo名 ☆ スター数：説明 [PR #番号]` の1行形式とし、PR に直接リンクします。マージ日時は掲載しません。日本語では「逆畳み込み」、英語では “transposed convolution” と表記します。

PR の状態とスター数は編集時に GitHub から取得する静的な記録です。実行時の GitHub API 呼び出しはありません。
ESP-DL #332 は GitHub 上では closed ですが、[メンテナーによる内部 GitLab でのマージ報告](https://github.com/espressif/esp-dl/pull/332#issuecomment-5658820520) を根拠にマージ済みに分類しています。

## 確認

ローカル Chromium / Playwright で、320・390・768・1440 px の日英表示、キーボードによる開閉、JavaScript 無効時、動きを減らす設定、ランダムな再描画、見出し URL、印刷後の開閉状態、ファイルの直接表示を確認しています。本文・リンクと OSS の分類も確認済みです。

日本語ページの初期読み込み対象は HTML / CSS / JS の3ファイルで、非圧縮の合計は 50,945 bytes です。変更前（`76f4f68`）は HTML / CSS / WebP の 93,291 bytes でした。初期表示からプロフィール画像を外した変更を含みます。PDF、リンク先の画像、HTTP ヘッダーは比較対象に含めません。現在の3ファイルを個別に gzip 圧縮した合計は 14,658 bytes ですが、実際の転送量は配信サーバーの圧縮設定に依存します。
